# What's for dinner? Design package (2026-11-08)

To be stored in the app's repository (suggestion: `docs/design/` or `apps/<app>/design/`).

- `wireframes-final.html`: open in a browser. Tabs: Play (clickable prototype), Wireframes, Plan, Guide, Logo and colours, Icons. Works offline, except the fonts (Google Fonts).
- `PLAN.md`: scope, product rules and decisions.
- `GUIDE.md`: usage guide (pieces, palette, icons, logo, flows, copy, accessibility).
- `tokens-wfd.css`: palette B "Verde de feira", `--wfd-*` variables, light and dark.
- `icons/`: 33 SVG icons (24 grid, 1.5 stroke, `currentColor`) and `sprite.svg`.
- `brand/`: logo v0 (mark, mark with name, app icon) and README.
- `screenshots/`: images of the wireframes and icons.

Visual base: the SkiroLiro design system (`dinotudor/design-system`). Visual reference: [`screenshots/wireframes-light.png`](screenshots/wireframes-light.png), [`screenshots/wireframes-dark.png`](screenshots/wireframes-dark.png), [`screenshots/icons.png`](screenshots/icons.png) and the offline prototype [`wireframes-final.html`](wireframes-final.html).
Decisions: reactions with any emoji; day responses in English (soft version per family, later); Enjoei per person; icons only for app use, emojis for responses, scores and reactions.
