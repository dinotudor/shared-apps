# What's for dinner? Pacote de design (2026-11-08)

Para registrar no repositório do app (sugestão: `docs/design/` ou `apps/<app>/design/`).

- `wireframes-finais.html`: abrir no navegador. Abas Play (protótipo clicável), Wireframes, Plano, Guia, Logo e cores, Ícones. Funciona offline, exceto as fontes (Google Fonts).
- `PLANO.md`: escopo, regras de produto e decisões.
- `GUIA.md`: guia de uso (peças, paleta, ícones, logo, fluxos, textos, acessibilidade).
- `tokens-wfd.css`: paleta B "Verde de feira", variáveis `--wfd-*`, claro e escuro.
- `icons/`: 33 ícones SVG (grade 24, traço 1.5, `currentColor`) e `sprite.svg`.
- `brand/`: logo v0 (marca, marca com nome, ícone do app) e README.
- `screenshots/`: imagens dos wireframes e ícones.

Base visual: design system SkiroLiro (`dinotudor/design-system`). Páginas publicadas como artefato: https://claude.ai/artifact/KHJ7ACQG7n5WvGSdjeXseP (privada).
Decisões: reações com qualquer emoji; respostas do dia em inglês (versão soft por família, depois); Enjoei por pessoa; ícones só de uso do app, emojis para respostas, notas e reações.
